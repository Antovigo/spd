Residual stream on the probe planes

Each point is one prompt at the = token; columns are stream positions — block outputs (after N) interleaved with post-attention states (attn N), so Δ into an "attn" column is that attention's write and Δ into an "after" column that MLP's write. Rows 1–3: the stream projected on that layer's own probes for a, b, and the result — the data each block works with. Row 4: every position on the fixed final-layer result probe — the final state being constructed. Δ modes color each point by its movement from the previous position, measured in the panel's own plane (or full-resid norm), on one shared scale across all panels.
