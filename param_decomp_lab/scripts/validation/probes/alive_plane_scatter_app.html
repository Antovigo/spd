Residual stream on the probe planes — real vs. alive-only circuits

Each point is one prompt at the = token; columns are stream positions — block outputs (after N) interleaved with post-attention states (attn N). Rows 1–2: the stream projected on that layer's own probes for a and b — the data each block works with. Row 3: every position on the fixed final-layer result probe — the final state being constructed. data picks which of three sources is shown: the real model, or a circuit with only hidden-alive / only output-alive components active (delta off, everything else hard zero — the same masking `find_alive_subcomponents` uses). All three are captured over the exact same sampled points, so they're directly comparable. distortion colours by each point's plane-projected distance from the real model (meaningless — and disabled — while viewing the real model itself). causal importance colours every panel by one selected alive subcomponent's CI on that prompt (read from the real model, so it doesn't depend on which source is shown).
