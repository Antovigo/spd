Residual stream on the probe planes — real vs. alive-only circuits

Each point is one prompt at the = token. view picks the layout: all layers columns are stream positions — block outputs (after N) interleaved with post-attention states (attn N) — for one chosen period; all periods columns are periods instead, for one chosen layer. Rows 1–2: the stream projected on that layer's own probes for a and b — the data each block works with. Row 3: the result probe fixed to one picked layer (probe layer, default final), evaluated at whichever stream layer each column implies. data picks which source is shown: the real model, or a circuit with only output-alive (or, on a dual-CI checkpoint, only hidden-alive) components active (delta off, everything else hard zero — the same masking `find_alive_subcomponents` uses). Every source is captured over the exact same sampled points, so they're directly comparable. distortion colours by each point's plane-projected distance from the real model (meaningless — and disabled — while viewing the real model itself). causal importance colours every panel by one selected alive subcomponent's CI on that prompt (read from the real model, so it doesn't depend on which source is shown). The Δ-from-previous-position colour modes and displacement arrows only make sense across stream positions, so they're disabled in the all-periods view.
