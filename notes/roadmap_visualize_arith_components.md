# Objective 1
Causal-importances are imprecise and possible biased. A better metric would be to run the model with only the one component of interest ablated, and measure the KL divergence of the output at the last position compared to the original model. So, first, we need to find all alive components, then run the model with each component individially ablated on each of the addition prompts. This way, we can store the original predicted token and its probability, the token we get instead and its probability, the KL between the two. Also, I would like to store the normalized inner activation of the subcomponent: the dot product between the input activations to this layer and the V vector of the subcomponent, normalized to norm 1 (i.e. x \cdot V/||V||). Also collect the norm of the subcomponent (||U||×||V||) and the causal importances. Think carefully about in what order to run the batches to save compute. Write a script to collect all this data efficiently and save it to the run’s folder. Then, run it on the add-refine-treat-01 decomposition.

# Objective 2
Write a new visualization applet. It should first identify the periodicity of each subcomponent, using the ablation-derived KLs as a metric for activation (use autocorrelation, as the periodic signal is not a sinusoid). Then, the applet should display a grid of plots: one for each component corresponding to a given frequency. The x-axis and y-axis should be the operands of the addition, as usual. Depending on the user’s selection, the color could be either the causal importances, the KL upon ablation, the normalized inner activation, the original predicted token or the token predicted by the ablated model.
Run the applet headlessly to check that it works.
